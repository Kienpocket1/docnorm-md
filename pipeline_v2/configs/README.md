# Runtime configuration

Pipeline hiện lấy cấu hình runtime từ CLI arguments, environment variables và
web launcher. Không commit token, API key, đường dẫn tuyệt đối của máy cá nhân
hoặc tài liệu nội bộ vào thư mục này.

Nếu cần thêm cấu hình mẫu, dùng hậu tố `.example.yaml` hoặc `.example.json` và
chỉ để placeholder.
